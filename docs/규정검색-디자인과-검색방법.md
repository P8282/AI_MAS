# 규정 검색: 화면 디자인과 검색 방법

`lib/regsearch.js`(화면)와 `규정/js/regdb.js`(검색 엔진)를 읽고 정리한 설명입니다. 코드가 기준이며, 이 문서와 코드가 다르면 코드를 따르세요.

## 1. 구조
```
index.html ──> lib/regsearch.js (화면: 오버레이, 목록·상세, 필터)
                    │  처음 열 때 불러옴
                    ▼
               규정/js/regdb.js (검색 엔진, DOM 의존 없음)
                    │
      ┌─────────────┼───────────────────────────┐
      ▼             ▼                           ▼
 data/regulation-index.json   regulations/<규정>/articles.json   법령해석/조달청/
 data/keywords.json           annexes.json · explanations.json    (관련 해석)
 (먼저 읽음: 즉시 검색)        (필요할 때만 규정별로 읽음)
```
- **지연 로딩**: 처음에는 경량 인덱스와 키워드 사전만 읽습니다. 조문 본문은 본문 검색이나 상세 보기 때 규정 단위로 불러옵니다.
- **엔진과 화면 분리**: `regdb.js`는 다른 웹앱(퀴즈, AI 질의응답 등)에서도 그대로 쓸 수 있습니다.
  ```js
  const db = new RegDB({ base: "규정/" });
  await db.init();
  const q = db.parse("국가계약법 시행령 제37조");
  const hits = db.searchIndex(q);                         // 즉시 결과
  await db.searchBody(q, {}, (newHits, prog) => { … });   // 본문 검색(점진)
  const a = await db.getArticle("STATE_CONTRACT_ENFORCEMENT_ART_37");
  ```

## 2. 검색 방법

### 2.1 질의 해석 (`RegDB.prototype.parse`)
입력 하나를 아래 순서로 나눕니다.
1. **규정명**: 별칭(예: 국계법, 국가계약법)을 긴 것부터 찾습니다. "국가계약법 시행령"이 "국가계약법"보다 먼저 잡힙니다. 공식 이름이 아닌 주제어 별칭(예: '적격심사')만 있고 조 번호가 없으면 규정 필터가 아니라 검색어로 봅니다.
2. **조·항 번호**: `제37조`, `제37조의2`, `제1항`. 숫자만 입력해도(예: `37`) 조 번호로 봅니다.
3. **종류 낱말**: `시행령`, `시행규칙`, `예규`, `고시` 같은 낱말은 종류 필터로 바꿉니다.
4. **초성**: `ㄱㅇㅂㅈㄱ`처럼 자음만 2자 이상이면 초성 검색입니다.
5. **검색어**: 나머지 낱말. 키워드 사전의 유의어를 함께 찾습니다.
   - 비율 표기: `0.075`, `0.05%`를 입력하면 법령 표기인 `1천분의 0.75`, `1천분의 0.5`로도 찾습니다.

**비교용 정규화**: 공백, 가운뎃점, 괄호, 따옴표, 하이픈 등을 지우고 소문자로 바꿔 비교합니다(숫자 사이 소수점은 남김). 원문 줄바꿈 때문에 글자 사이에 공백이 끼어도 찾습니다.

### 2.2 1단계: 인덱스 검색 (즉시)
제목·번호·키워드·장절에서 찾아 점수를 매깁니다. 낱말이 여러 개면 **모두** 맞아야 결과에 들어갑니다.

| 맞은 곳 | 점수 |
|---|---|
| 조 번호 일치 | 규정명과 함께 1000 / 번호만 600 |
| 제목과 같음 · 제목이 검색어로 시작 · 제목에 포함 | 500 · 420 · 330 |
| 키워드와 같음 · 키워드에 포함 | 350 · 220 |
| 조 번호 글자(예: 제37조)와 같음 | 300 |
| 장·절 이름에 포함 | 90 |
| 초성 시작 · 초성 포함 | 300 · 200 |

감점: 삭제 조문 −300, 부칙 −200, 시행 예정 −5, 별표 −2. 같은 점수면 규정 순서대로 보여 줍니다.

### 2.3 2단계: 본문 검색 (점진)
규정을 하나씩 불러오며 조문·별표 본문에서 검색어를 셉니다. 점수는 `100 + min(40, 맞은 횟수 × 4)`이고, 조 번호를 함께 쓰면 +800, 규정명을 함께 쓰면 +100입니다. 규정 하나가 끝날 때마다 결과를 더하며, 화면에 "본문 검색 중… n/435 규정"이 표시됩니다.

### 2.4 필터
- **종류**: 법률 · 시행령(대통령령) · 시행규칙(부령) · 계약예규 · 행정규칙(훈령·고시·지침·공고) · 법령해석례
- **분야**: 국가계약, 지방계약, 조달사업·조달청, 방위사업 등. 끈 분야는 이 기기에 기억합니다(`localStorage` `pps.regGrp`).
- **부칙·삭제 포함**: 기본은 숨김. 조 번호로 찾을 때는 보입니다.
- **규정 안에서만**: 규정을 고르면 그 규정 안에서만 찾습니다.

## 3. 화면 디자인
- **오버레이 하나**: 페이지 위에 검색 창이 뜹니다. 닫기·배경 누르기·브라우저 뒤로가기로 한 단계씩 돌아갑니다(`history.pushState`).
- **화면 너비에 따라**
  - 1000px 이상(PC): 왼쪽 검색·목록, 오른쪽 본문의 2단
  - 그보다 좁으면(휴대폰·태블릿): 목록과 상세를 번갈아 보는 1단
- **글자 크기**: `가−`/`가＋`, 16~28(기본 20), 이 기기에 기억(`pps.regFont`)
- **첫 화면**: 추천 검색어 칩(계약보증금, 선금, 수의계약, 다수공급자계약, 지체상금, `지체상금 0.075` 등), 분야별 규정 목록(규정 수·조문 수), 개정 알림(있을 때)
- **결과 목록**: 40개씩. 규정 종류별 색 태그, 조 번호·제목, 본문 발췌(검색어 강조), 시행일과 관련 규정
- **조문 상세**
  - 맨 위: 경로(규정 › 장), 조 번호·제목
  - **원문** 상자: 항·호·목 들여쓰기, `<개정 …>` 이력은 작은 꼬리표
  - **AI 설명** 상자: 원문과 구분해 '규정 원문 아님'으로 표시(`explanations.json`이 있을 때만)
  - **대응 조문**: 국가계약법 ↔ 지방계약법 ↔ 방위사업 등 같은 내용 조문(`data/correspondence.json`)
  - **관련 조달청 해석 N건**: 접힌 목록, 누르면 본문(`법령해석/조달청/`)
  - **출처**: 모두 법제처 국가법령정보센터 링크. 원래 PDF 링크였던 조문·별표는 이 저장소에서 법제처 링크로 바꿈(README §5)
- **어두운 화면**: 기기의 다크 모드를 따릅니다(`prefers-color-scheme`).
- **색**: CSS 변수(`--paper`, `--ink`, `--crimson` 등)를 쓰고, 변수가 없으면 기본값(흰 바탕, 진한 갈색 글자, 진홍 강조)으로 그립니다. 이 저장소의 `index.html`은 변수를 정하지 않으므로 기본값으로 보입니다.

## 4. 데이터 형식
조문 ID 예: `STATE_CONTRACT_ACT_ART_12`(국가계약법 제12조), 화면 표시 ID 예: `국가계약법-제12조`.
