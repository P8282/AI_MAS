# AI_MAS — 규정 DB와 규정 검색 (AI 강의 자료)

공공조달 관련 법령·행정규칙 435개를 조문 단위로 정리한 규정 DB와, 그것을 찾아보는 규정 검색 화면입니다. AI 강의("AI 기초자료를 위한 GitHub 활용")의 자료 제공용 저장소입니다.

> 이 저장소의 법령·규정은 열람용 사본입니다. **중요한 판단은 법제처 국가법령정보센터(law.go.kr)의 현행 원문으로 확인하세요.**

## 1. 무엇이 들어 있나
| 경로 | 내용 |
|---|---|
| `index.html` | 규정 검색을 여는 페이지(이 저장소에서 새로 만든 파일) |
| `lib/regsearch.js` | 규정 검색 화면(디자인·화면 동작) |
| `규정/js/regdb.js` | 검색 엔진(화면과 무관, 다른 웹앱에서도 사용 가능) |
| `규정/data/` | 규정 목록(`regulations.json`), 검색 인덱스, 키워드 사전, 대응 조문 표, 개정 알림 |
| `규정/regulations/<규정>/` | 규정별 조문(`articles.json`)·별표(`annexes.json`)·메타데이터, 이전 버전(`history/`), AI 설명(`explanations.json`, 51개 규정) |
| `규정/markdown/` | 규정별 열람용 마크다운 436개 — AI에 올리기 가장 쉬운 형태 |
| `규정/tools/`, `규정/config/` | DB를 만드는 도구와 법제처 API 도구, 설정(원래 사이트의 점검 서버·관리자모드·Sites 연동 도구는 뺌) |
| `법령해석/조달청/`, `법령해석/재정경제부/` | 조달청 법령해석(민원 회신 944건, 법적 효력 없음)·재정경제부 해석 목록. 규정 검색의 '관련 조달청 해석'이 읽음 |
| `docs/` | 이 저장소에서 새로 쓴 안내: [검색 화면과 검색 방법](docs/규정검색-디자인과-검색방법.md), [법제처 API 연결 방안](docs/법제처-API-연결.md) |

## 2. 출처와 기준일
- 복사 원본: `P8282/PPS_cert` `main` 커밋 `1d17b30` (2026-11-07, PR #697). 복사한 파일은 고치지 않았습니다. 예외는 `lib/regsearch.js` 한 곳입니다: 조문 상세 '출처' 칸의 원문 PDF 링크를 법제처 링크로 바꿨습니다(§5).
- 복사하지 않은 것: `규정/pdf/`(원문 PDF), `규정/ENCRYPTION.md`(원래 사이트의 보호 방식 문서), `규정/docs/`(작업 이력), `규정/README.md`(원래 사이트의 규정 DB 운영 설명서), 원래 사이트의 점검 서버·관리자모드·Sites 연동 도구, `법령해석/조달청 법령해석.html`(원래 사이트 전용 화면), 표준교재·문제은행 등 나머지 전부.
- 규정 본문: 법제처 국가법령정보 공동활용 API로 받은 규정 431개 + PDF에서 옮긴 규정 4개. **기준일은 규정마다 다릅니다**(`규정/data/regulations.json`의 `effective_date`). 시행 예정본이 포함된 규정이 있습니다(예: 중소기업기술혁신법 2027-03-30).
- 개정 알림(`규정/data/update-status.json`)의 마지막 점검일은 2026-10-11입니다.
- AI 설명(`explanations.json`)은 규정 원문이 아니라 AI가 쓴 요약이며 **검토 전**(`reviewed: false`)입니다. 화면에도 '규정 원문 아님'으로 표시됩니다.

## 3. 보는 방법
```bash
python3 -m http.server 8000      # 저장소 맨 위 폴더에서
# 브라우저로 http://localhost:8000/ 열기
```
- 파일을 더블클릭해서 열면(`file://`) 브라우저가 데이터 읽기를 막아 검색이 되지 않습니다. 위처럼 간단한 서버로 여세요.
- 검색 예: `계약보증금`, `국가계약법 시행령 제50조`, `지체상금 0.075`, `ㄱㅇㅂㅈㄱ`(초성)

## 4. 내 DB로 복사해 쓰기 (강의 참가자용)
1. 이 저장소 화면에서 **Use this template → Create a new repository → Private** 선택
   (공개 저장소를 포크하면 복사본도 공개로만 만들어집니다. 회사 메모를 넣으려면 템플릿으로 비공개 복사본을 만드세요.)
2. 규정 찾기: `규정/markdown/<규정 이름>.md`
3. AI에 쓸 때: 필요한 파일만 내려받아 올리고 "올린 자료만 근거로, 조문 번호를 표시해 답하라"고 질문
4. 복사본은 이 저장소가 갱신돼도 **자동으로 바뀌지 않습니다.** 기준일을 확인하고 법제처 원문과 대조하세요.
5. 단가·원가·인증서·계정 정보는 올리지 마세요.

## 5. 알려진 제한
- 원문 PDF는 넣지 않았습니다. 원래 PDF 링크가 있던 조문·별표 1,567개(52개 규정)는 '출처' 칸에 **법제처 국가법령정보센터 링크**를 대신 보여 줍니다. 주소 규칙은 PPS_cert `lib/regpop.js`와 같습니다.
  - 법령(법률·시행령·시행규칙 등): `law.go.kr/법령/<이름>/제N조`
  - 행정규칙: 저장된 법제처 주소(`source_url`), 없으면 `law.go.kr/행정규칙/<이름>`
  - 법령해석례(18-0366): 링크 없음
  - 저장된 법제처 주소가 없는 규정 4개(지방자치단체 입찰 및 계약집행기준, 지방자치단체 입찰시 낙찰자 결정기준, 벤처나라 등록 물품·서비스 지정 관리 규정, 우수재활용제품(GR) 품질인증기준(안))는 이름으로 만든 주소입니다. 법제처에서 열리는 것을 저장소 소유자가 확인했습니다(2026-11-07).
  - 데이터의 `pdf_path`·`source_path` 값은 고치지 않았습니다(출처 칸에 원본 파일 이름과 쪽수가 글자로 남습니다).
- `규정/tools/`의 일부 도구는 원래 저장소의 다른 폴더(`표준교재/`, `원문/`)를 읽습니다. 이 저장소에서는 그대로 돌지 않는 것이 있습니다(예: `fetch_lawgokr.py`의 기본 실행). 이 저장소에서 쓸 수 있는 것은 [법제처 API 연결 방안](docs/법제처-API-연결.md)에 정리했습니다.
- 개정 알림은 `규정/data/update-status.json`만 읽습니다(원래 사이트의 점검 서버는 부르지 않음).

## 6. 인증키
법제처 API 인증키(OC)·토큰은 이 저장소에 넣지 않습니다. 환경 변수 `LAWGO_OC`로만 씁니다.
